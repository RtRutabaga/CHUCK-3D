CHUCK 3D - Waterdeep progress demo - October 9, 2026

Windows 10/11, 64-bit. Keyboard and mouse. This is a work-in-progress demo.

1. Extract the entire ZIP to a folder. Do not run the EXE inside the ZIP.
2. Double-click Chuck3D.exe in the extracted folder.
3. Choose New Game. Follow the PC tutorial prompts as you explore.

Keep the Chuck3D and Engine folders beside the executable. Unreal Editor,
Blender, Git and the source repository are not needed to play.

If Windows reports a missing Microsoft Visual C++ runtime, run the included
Prerequisites/vc_redist.x64.exe, then start Chuck3D.exe again.

Controls
WASD / arrow keys: move. Mouse: look.
Left Shift: toggle running. Space: jump / climb.
Left Ctrl while moving: sprint on all fours; Space after a straight run-up
of at least a metre gives a longer sprint leap.
Q / E: strafe left / right; Space while strafing: side jump.
C: dodge roll. Left mouse button: scratch. F: talk.
R: return to the docks. Esc: exit.

The route leads through the docks and sewer, then returns to the opened
tavern and its cellar. Falling into the cellar's open sky ends this demo.
The Fall to Chult cutscene is not included yet.

This is a preview of current progress, with provisional graphics and gameplay.
